# timezone-converter-linux

贴在 Ubuntu 桌面上的时区卡片。默认转换柏林和上海，也可以加入其他城市，再把不需要的城市或整张卡片移除。

在 X11 会话下使用。需要系统自带的 `/usr/bin/python3`（已安装 PyGObject）、GTK 4 和 libadwaita。

## 功能

- 卡片直接浮在桌面上，圆角半透明，不进任务栏。拖动标题或空白处可以换位置，位置会记住。
- 默认显示柏林和上海。点时间可以改这个城市的日期和钟点，其他城市按同一时刻换算，并标出次日或前一天。
- 欧洲城市会标出当前是夏令时还是冬令时。时差跟着这个日期走：柏林夏令时上海快 6 小时，冬令时快 7 小时。上海这类没有夏令时的城市只显示偏移。
- 平时走实时时钟。设定时间后会暂停，点「现在」回到当前时间。
- 点 **+** 搜索城市、拼音、英文或 IANA 时区名来添加地点，最多 8 个。编辑模式下可以移除地点，或把另一个城市设为基准。时差和标题都按基准城市计算。
- 菜单里可以开关实时时钟、始终置顶和登录时加载。关闭置顶后，卡片贴在桌面上，其他窗口可以盖住它。

## 使用

加载到桌面，并在下次登录时自动出现：

```bash
./timezone-desk/install.sh
```

卡片出现在主屏幕右上角。

- 拖动标题或空白处移动卡片。点在时间、**+** 或 **•••** 上不会把卡片拖走。
- 点某个城市的时间，用左右箭头改日期、小时和分钟。下面列出其他城市的同时刻。
- 点 **+** 添加地点。也可以点 **•••**，选「添加地点」。
- 换基准城市：点 **•••**，选「编辑地点」，再点另一个城市下的「设为基准」。点「完成」退出编辑。编辑时城市左侧的 **−** 用来移除，至少保留一个城市。
- 右键卡片，或点 **•••**，可以关闭实时时钟、关闭始终置顶，或取消登录时加载。
- 「从桌面移除」会关掉卡片并取消登录时自动出现。地点配置还在。

从桌面卸下：

```bash
./timezone-desk/uninstall.sh
```

连同已保存的地点一起删除：

```bash
./timezone-desk/uninstall.sh --purge
```

地点、位置和置顶状态写在 `~/.config/timezone-desk/config.json`。运行日志在 `~/.config/timezone-desk/run.log`。

也可以不安装，直接运行。再次运行会回到已经打开的那一张卡片。

```bash
/usr/bin/python3 timezone-desk/timezone_desk.py
/usr/bin/python3 timezone-desk/timezone_desk.py --quit
/usr/bin/python3 timezone-desk/timezone_desk.py --remove
```

`--quit` 只关闭卡片。`--remove` 同时取消登录时加载。
